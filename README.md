# Akhilesh Palve — Cybersecurity Portfolio

A high-performance, modern cybersecurity portfolio and technical research blog for **Akhilesh Palve**, built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

- **Specialization**: Vulnerability Assessment & Penetration Testing (VAPT), Active Directory Security, Cloud Security
- **Education**: B.Tech CSE (Cybersecurity & Forensics) — MIT ADT University, Pune (2022–2026)
- **Certifications**: Security+, CCST Cybersecurity, Certified Cyber Ninja, CNSS, Palo Alto Fundamentals
- **Platforms**: Bugcrowd, Hack The Box (15+ machines rooted), CTF Competitor (nCreeps)

## 🚀 Key Sections
- **Intro & Terminal Recon**: Professional summary, social links, and live GitHub activity tracker.
- **Experience**: Detailed timeline covering leadership at CyArt (Team Lead), The DEVS (Wing Head), Bugcrowd, and internships.
- **Projects**: Security payloads including VARYS (AI Forensics), Phishing Email Analyzer, SSH Honeypot, Secure Document Storage, and Custom SIEM/SOC.
- **Field Notes & Research**: Technical articles on Active Directory Enumeration, Phishing Triage, and Cloud Metadata Security.
- **Capabilities Matrix**: Offensive, defensive, tooling, and scripting skills with MITRE ATT&CK integration.

## 🛠️ Tech Stack
- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Themes**: next-themes (Dark & Light support)
